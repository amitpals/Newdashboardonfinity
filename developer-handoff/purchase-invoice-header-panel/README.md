# Purchase Invoice Header Panel

Standalone HTML/CSS handoff for the `Purchase Invoice` window header panel.

## Files

- `index.html`
- `styles.css`

## Included

- vendor identity row
- compact invoice summary subline
- action buttons:
  - `Save Draft`
  - `Submit Invoice`
  - `Attach Bill`
  - `Match PO`

## Notes

- this is only the header panel block, not the whole window
- typography uses `Roboto`
- primary blue is `#0083da`
- layout follows the in-app reference:
  - lightweight blurred shell row
  - inner rounded surface
  - left identity block
  - right action buttons
